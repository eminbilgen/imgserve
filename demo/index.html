Open source · PHP · no dependencies

Resize images on the fly.

One PHP file turns a single original into the exact size, crop and format each screen needs, caches it, and tells browsers how long to keep it. Change the controls and watch the real response.

Safe by default

Only files inside one folder can be served. Traversal, odd paths and non-images are refused, and sizes snap to a short list so nobody can fill your disk.

Cached and cheap

The first request renders, every later one is a file read. ETag and Cache-Control let browsers and CDNs skip the download entirely.

Modern formats

fmt=auto sends WebP to browsers that accept it and a clean JPEG or PNG to the rest.
